# GanttProject – Construction Schedule

## Overview
This folder contains the editable construction project schedule developed using **GanttProject** for a hypothetical high-rise residential development in Gurugram, Haryana.

The schedule presents the proposed sequence of construction activities, planned durations, start and finish dates, and key project milestones across the development timeline.

## Project Scope
The schedule covers the major phases of a residential high-rise construction project:

- Site mobilisation and preparation
- Excavation and foundation works
- RCC structural construction
- Masonry and plastering
- Mechanical, Electrical and Plumbing (MEP) works
- Flooring, painting and finishing
- Testing, commissioning and handover

## Key Deliverables
- Editable GanttProject schedule file
- Activity-wise construction timeline
- Planned start and finish dates
- Indicative activity sequencing
- Key project milestones
- Gantt chart visualisation

## Software Used
- GanttProject

## Files
- `Residential_High_Rise_Development.gan` – Editable project schedule file.
- `Gantt_Chart_Screenshots/` – Screenshots of the schedule and Gantt chart.

## Important Note
This is an independent academic/portfolio planning exercise. The schedule, activity durations, dates and sequencing are illustrative assumptions developed for demonstration purposes. They do not represent an approved construction programme or an actual DLF or Godrej project schedule.

The schedule should be opened and reviewed in GanttProject before being treated as a validated project baseline.
