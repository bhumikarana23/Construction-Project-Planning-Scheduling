# Documentation – Construction Project Planning

## Overview
This folder contains supporting documentation explaining the scope, assumptions and methodology adopted for the hypothetical high-rise residential construction planning project.

The documentation provides context for the schedule and explains the approach used to organise the major construction activities.

## Documentation Coverage

### 1. Project Description
Overview of the hypothetical residential development, including the project scenario, indicative scale, location and planning objectives.

### 2. Project Scope
Identification of the major construction work packages, from site mobilisation through structural works, MEP installation, finishing and handover.

### 3. Planning Assumptions
Details of the assumed project duration, activity durations, construction sequence and other planning inputs used to prepare the schedule.

### 4. Scheduling Methodology
Explanation of the approach used to break down the project into activities, organise work packages and prepare the indicative construction timeline.

### 5. Project Limitations
Clarification of the assumptions and limitations associated with this independent planning exercise.

## Project Information
- **Project Type:** High-rise residential development
- **Location:** Gurugram, Haryana
- **Development Configuration:** 3 towers × 25 floors
- **Indicative Project Budget:** ₹150 crore
- **Illustrative Project Duration:** January 2026 – December 2027

## Purpose
The documentation supports the project schedule by providing a clear explanation of the planning assumptions, scope and methodology.

## Important Note
This is an independently developed academic/portfolio project. All project information and planning assumptions are illustrative and are not based on confidential company records or an actual DLF or Godrej project.
