# Excel – Construction Schedule

## Overview
This folder contains the Excel-based construction schedule developed to organise and present the planned activities for a hypothetical high-rise residential development in Gurugram, Haryana.

The workbook provides a structured activity register to support construction planning, timeline preparation and schedule review.

## Key Components
The Excel workbook is intended to organise:

- Construction activity descriptions
- Activity-wise planned durations
- Planned start and finish dates
- Activity sequencing and dependencies
- Major construction phases
- Key milestones
- Overall project timeline

## Construction Phases Covered
1. Site mobilisation and preparation
2. Excavation and foundation
3. RCC structural works
4. Masonry and plastering
5. MEP installation
6. Finishing works
7. Testing, commissioning and handover

## Software Used
- Microsoft Excel

## File
- `GanttProject_Construction_Schedule.xlsx` – Excel workbook containing the construction activity schedule.

## Purpose
The workbook provides a convenient format for reviewing construction activities, understanding the planned execution sequence and organising schedule information.

## Important Note
All project information, dates, durations and activity assumptions are illustrative and created for portfolio demonstration. They are not actual project records, approved contractor schedules or confidential company information.
