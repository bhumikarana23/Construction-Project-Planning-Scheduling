# Reports – Construction Planning & Scheduling

## Overview
This folder contains the formal project report documenting the construction planning and scheduling exercise for a hypothetical high-rise residential development in Gurugram, Haryana.

The report presents the project scenario, planning assumptions, construction activity breakdown, proposed execution sequence and overall project timeline.

## Report Contents
The report is intended to cover:

- Project overview and development assumptions
- Project scope and major construction packages
- Work Breakdown Structure (WBS) and activity grouping
- Indicative activity durations
- Planned construction sequence
- Key project milestones
- Overall project schedule
- Planning assumptions and limitations

## Project Timeline
The illustrative project baseline covers the period:

**1 January 2026 – 31 December 2027**

## Software Used
- GanttProject
- Microsoft Excel

## File
- `Construction_Planning_Schedule_Report.pdf` – Project planning and scheduling report.

## Purpose
The report provides a consolidated presentation of the planning approach and proposed construction timeline. It is intended to demonstrate an understanding of construction sequencing, activity planning and schedule documentation.

## Important Note
This report is an independent portfolio exercise. The project details, timeline, durations and assumptions are hypothetical and should not be interpreted as an actual construction project programme or an approved baseline schedule.
