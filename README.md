# Construction Project Planning & Scheduling

<badge>Portfolio Project</badge>

## 1. Project Overview

This project focuses on developing a structured construction planning and scheduling framework for a hypothetical high-rise residential development in Gurugram, Haryana.

The project involves organising construction activities, establishing execution sequences, defining activity durations, identifying milestones and developing a baseline project schedule.

Using GanttProject and Microsoft Excel, the project demonstrates the application of construction planning and scheduling techniques for coordinating activities throughout the project lifecycle.

**Project Type:** Independent Portfolio Project  
**Project Domain:** Construction Planning | Project Scheduling | Project Management  
**Tools:** GanttProject | Microsoft Excel

## 2. Project Scenario

| Parameter | Details |
|---|---|

| Location | Gurugram, Haryana |
| Number of Towers | 3 |
| Floors per Tower | 25 |
| Indicative Project Budget | ₹150 Crore |
| Project Start Date | 1 January 2026 |
| Baseline Completion | 31 December 2027 |
| Project Duration | 24 Months |

*All project details and planning assumptions are hypothetical and created exclusively for portfolio demonstration. This is not an actual DLF or Godrej project.*

## 3. Project Objectives

- Develop a structured construction execution schedule.
- Identify major construction activities and work packages.
- Establish activity sequencing and logical dependencies.
- Assign indicative activity durations and planned timelines.
- Identify key project milestones.
- Develop a baseline schedule for progress monitoring.
- Organise project activities into a structured Work Breakdown Structure (WBS).

## 4. Planning Methodology

### 1. Project Scope & Work Breakdown

Identified major construction stages and divided the project into manageable work packages and activities.

### 2. Activity Identification

Organised construction activities covering:

- Site preparation and mobilisation.
- Excavation and foundation works.
- Structural and RCC works.
- Masonry and plastering.
- Mechanical, electrical and plumbing (MEP) works.
- Finishing and internal works.
- Testing, commissioning and handover.

### 3. Activity Sequencing

Established logical relationships and dependencies between construction activities to represent the proposed execution sequence.

### 4. Duration Estimation

Assigned indicative durations to activities based on the hypothetical project scope and planning assumptions.

### 5. Baseline Schedule Development

Prepared a project schedule covering the planned construction period, including activity timelines, milestones and sequencing.
